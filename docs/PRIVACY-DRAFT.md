# 개인정보 처리방침 초안 (법률 검토 전 — 공개 전에 반드시 검토)

가족 연결을 쓰면 입력 내용이 서버에 저장되므로, 공개하기 전에 처리방침을 만들고 동의 화면과 맞춰야 한다. 아래는 담아야 할 항목의 초안이다(법률 자문 아님).

| 항목 | 현재 앱의 내용 |
|---|---|
| 수집 항목 | 아이 애칭·생년월(생일은 월령 계산용)·성별, 키·몸무게, 발달 체크, 놀이·도서 기록, 심부름·메모·메시지·의견. 익명 로그인 ID. 실명·연락처·사진·위치는 받지 않음 |
| 민감정보 | 키·몸무게·발달 정보는 건강 관련 정보 → 동의 화면에서 별도 필수 체크로 받음 |
| 목적 | 가족 두 사람이 같은 놀이·성장 기록을 보는 것 |
| 보관 위치 | 구글 Firebase(Firestore), 서울 리전(`asia-northeast3`) |
| 접근 | 가족 구성원 2명. 서비스 운영자는 Firebase 콘솔에서 데이터를 볼 수 있음 → 처리방침에 명시하고 내부 열람 기준을 정할 것 |
| 보관 기간 | 연결을 해제하거나 가족 기록을 삭제할 때까지. 앱 안에서 즉시 삭제 가능 |
| 제3자 제공·위탁 | 구글(Firebase) 서버 이용 위탁 |
| 분석 | Analytics를 불러오지 않음(프로젝트에서도 끄는 것을 권장) |
| 이용자 권리 | 열람(앱 화면), 삭제(가족 기록 모두 삭제), 연결 해제 |
| 아동 | 아이 정보는 보호자가 입력. 앱의 이용자는 보호자 |
| 광고 | 없음 |

## 공개 전 할 일
- 처리방침 페이지 작성·링크를 동의 화면에 연결
- 개인정보 책임자·문의 방법 기재
- Firebase 콘솔에서 Google Analytics 끄기, App Check 설정
- 의료기기 소프트웨어 해당 여부(진단 표현 금지), CDC·WHO 이용 조건 확인 (`docs/DATA-SOURCES.md`)
