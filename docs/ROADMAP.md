# 로드맵

## 지금 (v0.3, Claude Artifact)
- 장점: 서버 없이 즉시 사용, 초대한 사람끼리 저장소 공유
- 한계: 주소가 claude.ai 아래, 초대된 계정만 접속·로그인 필요, 저장소가 이 페이지 전용이라 다른 가족의 평균 통계 표본이 작음, 광고·공개 서비스 불가

## 1단계: 홈 화면 앱처럼 쓰기 (비용 0)
- 폰 브라우저에서 앱 링크 열기 → "홈 화면에 추가"
- 위 한계는 그대로

## 2단계: 독립 PWA (공개 가능)
- (v0.5 완료) 저장소 호출은 `localBackend`/`getBackend` 어댑터로 분리됨. 남은 일: 같은 모양의 Firebase 구현을 끼우기
- 백엔드: Firebase(Auth + Firestore) 등. 보안 규칙: 아이 데이터는 가족 단위, `growth` 통계는 익명 집계만
- 정적 호스팅(GitHub Pages / Cloudflare Pages) + `manifest.webmanifest` + 서비스 워커
- 필요: 개인정보 처리방침, 아동·건강정보 동의 흐름

## 3단계: 구글 플레이
- 2단계 PWA를 TWA(Bubblewrap 등)로 감싸 등록
- 개인 개발자 계정(2023-11-13 이후 생성)은 비공개 테스트 12명 × 14일 연속 필요 (Google Play Console 안내)

## 콘텐츠
- 놀이 카드 96개 (v0.11, 월령 범위 포함, 0~36개월). 다음: 18·24개월 이정표 CDC 원문 대조 후 공개, 24개월 전용 카드, 추가 카드의 준비물·책 가이드
- 책·준비물: 구매 링크·공동구매는 출처 확인 후

## 데이터
- 0~12개월 이정표 세트(CDC 2·4·6·9·12·15개월)는 아직 없어, 12개월 미만은 18개월 세트가 대신 표시된다. 세트 추가 필요
- 도구·책 데이터는 북스타트(연 1회)·안전기준(월 1회) 갱신 주기에 맞춰 관리 (`docs/TOOLS-DATA.md`)

## 알림
- 타이머 알람은 앱이 열려 있을 때만 울린다. 백그라운드 알람과 엄마 폰 푸시(보고 도착 알림)는 Firebase 푸시(FCM) 단계에서 구현 (`docs/PAIRING.md`)

## 제안 (아직 안 만듦)
- 가족 연결(Firebase): 엄마·아빠 폰 연동, 심부름·보고 푸시 알림
- 심부름 반복(매주 금요일 등), 사진 첨부, 아빠가 엄마에게 "사 왔어" 한 줄 답장
- 책 목록 확대: 사용자가 준 목록을 확인해 `data/books.json`에 반영, 카테고리별 월령 세분
- 0~12개월 이정표 세트(CDC 2·4·6·9·12개월), 교정 월령(조산아)
- 주간 요약(엄마에게 일요일 저녁: 이번 주 놀이 시간·반응·완료한 심부름)
