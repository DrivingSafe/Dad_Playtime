# 0~36개월 도구·책 데이터 (`data/tools.json`)

"아빠의 저녁 15분 놀이" 앱용 도구·책·안전 데이터. 앱은 시작할 때 이 파일을 읽어 오늘 화면의 "도구·책 가이드"와 "안전 약속"을 월령에 맞게 보여 준다.

## 구조 원칙
- **트랙 A (공공·의학 기관)가 뼈대**: 아이사랑(보건복지부), CDC, AAP, 북스타트, 국립어린이청소년도서관, 한국소비자원 등. 41개.
- **트랙 B (엄마들 후기)는 A 유형에 붙는 예시**: `of`로 트랙 A 항목에 연결하고, 앱에서는 "엄마들이 많이 쓰는 예"로만 보여 준다. 단독 추천 카드로 쓰지 않는다. 22개.
- **보행기는 권장하지 않는다**: 도구 목록이 아니라 안전 항목(S6·S7)의 "쓰지 마세요"로만 다룬다.
- 기관이 **유형**만 제시한 항목은 `type:"generic"`, 실제 이름이 있는 항목(북스타트 도서 등)은 `type:"named"`.

## 필드
| 필드 | 설명 |
|---|---|
| `id` | `a_…`(트랙 A), `b_…`(트랙 B) |
| `track` | `A` / `B` |
| `name`, `type`, `cat` | 이름, generic/named, 분류(book·toy·play·song·gear·household) |
| `show` | 앱에서 보여 줄 월령 범위 `[최소,최대]` (개월) |
| `mo_src` | **출처가 말한 월령 원문** (예: "0~18개월(북스타트 1단계, 2026)"). 출처별로 단계 구분이 달라(북스타트 표준 19~35개월, 용인 13~24개월 등) 원문 그대로 저장 |
| `tip` | 아빠 15분 활용법. **기관 원문이 아니라 데이터 정리 과정에서 각색한 제안** |
| `src` | 출처 코드(쉼표 구분). `sources`에 정의 |
| `rel` | 신뢰도: A 공공·의학 기관 / B+ 복수 출처 반복 / B 후기·커머스 / B- 판매·광고성 가능 |
| `com` | 상업성: none / possible / high(판매자 계정·상품명 키워드) |
| `flags` | overstimulation, unverified_efficacy, commercial_keyword, stairs, magnet, small_parts, single_review, unverified_age, short_session |
| `limits` | 제조사 사용 한계 (월령·체중·중단 조건) |
| `of` | 트랙 B 항목이 붙는 트랙 A 항목 id |
| `avail` | generic / unverified(절판·판매 여부 확인 안 됨) / n/a |

`safety`는 월령 범위(`mo`)와 종류(`avoid` 쓰지 마세요 / `rule` 지킬 규칙 / `info` 참고)를 가진 안전 문장 모음이다.

## 앱 표시 규칙
- 오늘 화면 "도구·책 가이드": 월령(`show`)에 맞는 트랙 A 항목을 분류별로, 항목 아래에 "엄마들이 많이 쓰는 예"(트랙 B)를 접어서 보여 준다. 36개월 미만에는 작은 부품 안내를 붙인다.
- 트랙 B에는 신뢰도 라벨("여러 후기에서 반복", "후기", "판매·광고성 가능")과 주의 표시(자극, 판매 키워드, 자석 이탈 점검 등)를 같이 보여 준다. "국민템"이라는 표현은 인기의 근거로 쓰지 않는다.
- "안전 약속": 월령에 해당하는 규칙. 4~24개월 앱에서는 보행기 금지가 먼저 열려 있다.
- 효능 문구("시각 발달 촉진" 등)는 화면에 싣지 않고 `unverified_efficacy`로만 표시한다.
- 개발자 모드 패널에 데이터 개수(공공 A·후기 B·안전)가 표시된다.

## 갱신 주기
| 데이터 | 주기 | 이유 |
|---|---|---|
| 북스타트 도서 | 연 1회(2~4월) + 지자체별 수시 | 연도별 선정이 바뀌고 지자체마다 다름 |
| 국립어린이청소년도서관 사서추천 | 월 1회 | 매월·격월 공개 |
| CDC·AAP 지침 | 연 1회 | 개정이 드묾 |
| 안전기준·리콜(국가기술표준원, 한국소비자원) | 월 1회 | 리콜 반영이 시급 |
| 트랙 B(커머스·후기) | 분기 1회 | 상품 교체·단종이 잦음 |

## 한계 (데이터 제공 측 표기를 그대로 옮김)
- 아이사랑·북스타트코리아 본문은 자동 수집이 막혀 **검색 스니펫으로 확인**했고, 아이사랑 페이지의 게시·갱신일은 확인 불가다. 7~9개월 아이사랑 페이지는 미확보.
- 트랙 B는 후기 플랫폼·Threads·오늘의집·블로그·커머스 검색 기반이라 신뢰도가 중~하이고, "반복 확인"은 서로 다른 출처 2곳 이상에서 확인됐다는 뜻일 뿐 정량 수치가 아니다.
- 북스타트 과거 선정 도서(『우리 아기 첫 문』, 『우리아기 보러와요』, 『와! 무지개다!』 등)와 그레이트북스 도레미곰, 점퍼루 HNX64(단종), 리틀타익스 국내 판매 모델의 **판매·구성 여부는 확인 불가**(`avail:"unverified"`).
- 점퍼루 "approximately 9 months"는 시작/종료 월령 여부가 불분명하다. 리틀타익스 슬라이드 상한은 채널에 따라 5세·6세로 다르다.
- 안전 S12(침실 가구 추락 33.8%)는 언론 보도를 통한 2차 인용이다. 배포 전 한국소비자원 원문과 대조할 것.
- 어린이제품 공통안전기준(작은 부품 31.7mm 등)의 최신 개정일은 확인 불가. 국가법령정보센터에서 재확인할 것.
