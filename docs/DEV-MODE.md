# 개발자 모드

월령·일자에 따라 앱 화면이 어떻게 달라지는지 확인하는 도구. 일반 사용자에게는 보이지 않는다.

## 켜고 끄기
- **의견 탭 → 개발자 모드 [꺼짐|켜짐]** (가장 쉬움, 서버 없는 모드)
- 이름·월령 7번 탭: 화면 위 아이 이름이나 "만 N개월"을 3초 안에 7번 누르면 켜지고 같은 방법으로 끈다 (글자 선택은 막아 둠)
- 켜기: 주소 뒤에 `?dev=1` (예: `https://drivingsafe.github.io/Dad_Playtime/?dev=1`) 또는 의견 탭 맨 아래 "개발자 모드 켜기"
- 끄기: `?dev=0` 또는 패널 맨 아래 "개발자 모드 끄기"
- 켜면 오른쪽 아래에 `DEV` 버튼이 생긴다. 기준일을 옮기면 주황색으로 바뀐다.

## 엄마·아빠 화면 보기 (별도 앱 필요 없음)
- 개발자 모드를 켜면 **헤더에 [전체 | 아빠 | 엄마] 버튼**이 생긴다. 한 번에 바뀐다. `전체`는 4개 탭이 모두 보인다.
- 일반 사용(개발자 모드 없이)에서는 의견 탭 → **내 역할**에서 아빠/엄마를 바꿀 수 있다.
- 지금은 서버가 없어 같은 기기 안에서만 엄마·아빠가 연결돼 보인다(아빠가 보고하면 엄마 화면에 바로 뜸). 두 폰의 연결은 `docs/PAIRING.md`.

## PC 한 대로 두 폰 테스트 (가족 연결)
- **나란히 보기**: `https://drivingsafe.github.io/Dad_Playtime/dev-split.html` (로컬: `python3 -m http.server` 후 `/dev-split.html`). 왼쪽 아빠·오른쪽 엄마 화면이 각자 저장소·Firebase 로그인을 쓴다. 아빠에서 "새로 시작하기" → 코드 확인 → 엄마에서 코드로 합류.
- **버튼**: 둘 다 새로고침 / 모두 초기화(기록 + 로그인 삭제, 다음엔 새 익명 사용자) / 작은 폰 크기 / 폰별 새로고침·초기화.
- **직접 주소**: `index.html?profile=dad`, `?profile=mom` 처럼 `profile=`(영문·숫자 12자 이내)을 붙이면 같은 브라우저에서도 따로 동작. 화면에 보라색 "🧪 테스트 프로필" 배지가 뜬다.
- **코드 없이**: 일반 창 = 아빠, 시크릿 창 = 엄마로 열어도 된다.
- 주의: 테스트로 만든 가족 데이터는 서버에 남는다. 끝나면 의견 탭 → 가족 기록 모두 삭제.

## 기능
| 기능 | 설명 |
|---|---|
| 날짜 이동 | -1개월 / -1주 / -1일 / +1일 / +1주 / +1개월 / 오늘로, 날짜 직접 지정 |
| 월령 지정 | 생일 기준 "N개월 N일"로 바로 이동 |
| 현황 | 기준일, 만 개월·일, 30개월까지 D-day, 오늘의 놀이, 성장 그래프 구간·WHO 월령 |
| 7일 놀이 순환 | 현재 기록 기준으로 앞으로 7일 동안 어떤 놀이가 나오는지 표로 확인 |
| 월령별 WHO 값 | 12~48개월 3·50·97백분위 키·몸무게 (성별 기준) |
| 보기 역할 | 전체 / 아빠 / 엄마. 아빠는 "엄마의 눈", 엄마는 "아빠의 놀이" 탭이 숨겨진다. 전체는 모두 보임 |
| 초안 콘텐츠 | 원문 대조 전 이정표(18·24개월)와 카드를 보이거나 숨김. 끄면 일반 사용자 화면과 같음 |

## 동작 방식
- 앱의 `Date`를 한 겹 씌워서 앱 전체의 "오늘"이 함께 움직인다. 저장되는 기록의 날짜도 같이 옮겨진다.
- 실제 기록과 섞이지 않게 저장소를 `dpn_db_dev`로 분리한다. 처음 켤 때 실제 데이터를 한 번 복사해 온다. 개발자 모드를 꺼도 개발용 저장소는 남는다(실제 데이터는 그대로).
- 기준일 설정은 `dpn_dev_off`에 저장되어 새로고침 후에도 유지된다.

## 월령별 콘텐츠 (v0.9)
| 월령 | 이정표 세트 | 일반 사용자 | 개발자 모드 |
|---|---|---|---|
| ~23개월 | 18개월 (CDC 대조) | 표시 | 표시 |
| 24~29개월 | 24개월 (CDC 대조) | 표시 | 표시 |
| 30~35개월 | 30개월 (공개 중) | 표시 | 표시 |
| 36개월~ | 36개월(3세) | 표시 | 표시 |
- 18·24개월 세트는 CDC 공식 체크리스트와 문구를 대조해 공개했다(`docs/DATA-SOURCES.md`). 앞으로 대조 전 세트를 추가하면 `ready:false`로 두면 개발자 모드에서만 보인다.
- 놀이 카드는 카드마다 `age:[최소,최대)`(개월)를 가진다. 없으면 24~36개월용. 월령에 맞는 카드 풀에서 "약한 영역 우선·최근 5일 제외·날짜 순환"으로 고른다.
- 24~29개월 카드는 아직 30개월 이정표 항목에 연결돼 있다(24개월 전용 카드 미작성).

## 테스트
`node tests/dev.js` (자동 스크롤 + 개발자 모드), `node tests/age.js` (월령별 세트·카드 풀·역할별 탭)
