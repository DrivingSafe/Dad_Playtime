# 개발자 모드

월령·일자에 따라 앱 화면이 어떻게 달라지는지 확인하는 도구. 일반 사용자에게는 보이지 않는다.

## 켜고 끄기
- 켜기: 주소 뒤에 `?dev=1` (예: `https://drivingsafe.github.io/Dad_Playtime/?dev=1`) 또는 의견 탭 맨 아래 "개발자 모드 켜기"
- 끄기: `?dev=0` 또는 패널 맨 아래 "개발자 모드 끄기"
- 켜면 오른쪽 아래에 `DEV` 버튼이 생긴다. 기준일을 옮기면 주황색으로 바뀐다.

## 기능
| 기능 | 설명 |
|---|---|
| 날짜 이동 | -1개월 / -1주 / -1일 / +1일 / +1주 / +1개월 / 오늘로, 날짜 직접 지정 |
| 월령 지정 | 생일 기준 "N개월 N일"로 바로 이동 |
| 현황 | 기준일, 만 개월·일, 30개월까지 D-day, 오늘의 놀이, 성장 그래프 구간·WHO 월령 |
| 7일 놀이 순환 | 현재 기록 기준으로 앞으로 7일 동안 어떤 놀이가 나오는지 표로 확인 |
| 월령별 WHO 값 | 12~48개월 3·50·97백분위 키·몸무게 (성별 기준) |

## 동작 방식
- 앱의 `Date`를 한 겹 씌워서 앱 전체의 "오늘"이 함께 움직인다. 저장되는 기록의 날짜도 같이 옮겨진다.
- 실제 기록과 섞이지 않게 저장소를 `dpn_db_dev`로 분리한다. 처음 켤 때 실제 데이터를 한 번 복사해 온다. 개발자 모드를 꺼도 개발용 저장소는 남는다(실제 데이터는 그대로).
- 기준일 설정은 `dpn_dev_off`에 저장되어 새로고침 후에도 유지된다.

## 알려진 한계 (현재 앱 내용)
- 발달 체크(이정표)는 **CDC 30개월 한 가지**만 있다. 월령에 따라 이정표 세트가 바뀌지 않는다.
- 놀이 카드 선택은 월령이 아니라 "약한 영역 우선 + 최근 5일 제외 + 날짜 순환"으로 정해진다. 월령별 카드 구분은 아직 없다.
- 월령에 따라 달라지는 것은 헤더 월령, 30개월 D-day, 성장 그래프 구간과 백분위뿐이다.
- 월령별 콘텐츠를 만들려면 이정표 세트와 카드에 월령 범위를 추가하는 작업이 필요하다 (ROADMAP 참고).
