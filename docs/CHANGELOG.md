# 변경 이력
## v0.12 (2026-11-06)
- 오늘 화면 개편: 오늘의 놀이·오늘의 도서 카드가 메인. 카드 뒤에 다음 카드가 겹쳐 보이고, 좌우로 넘기면(드래그·화살표) 카드가 움직이는 애니메이션
- "이걸로 하기"를 누르면 바로 카운트다운 시작. 타이머는 화면 상단 고정 바로 분리, 끝나는 시각을 저장해 새로고침해도 계속. 끝나면 알람(진동·소리·알림) 후 "엄마에게 보고할까요?" 시트
- 보고 기준을 종류별로 분리: 놀이(아이 반응) / 도서(흥미·이해 반응) / 도구 놀이. 엄마 화면에도 구분해서 표시
- 고른 놀이·도서를 하루 동안 기억(새로고침해도 시스템 추천으로 되돌아가지 않음). 엄마가 놀이·도서를 각각 지시할 수 있음
- 도감을 전체 화면 시트로: 탭(놀이·도서·도구), 필터 칩, 2열 카드, 자세히 → 고르기. 도구는 도감에서 바로 시작
- 발달 체크인(요즘 이거 잘 하나요?) 하루 최대 3개
- 개발자 모드 진입: 이름 7번 탭, 헤더에 보기 역할 전환(전체·아빠·엄마). 의견 탭에 내 역할 바꾸기
- `tests/session.js` 추가, `recommend.js` 재작성 (`docs/TODAY-FLOW.md`)
