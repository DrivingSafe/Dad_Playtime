# PWA 테스트 가이드

## 먼저 알아둘 것
- PWA는 **https 주소**(또는 localhost)에서만 설치·오프라인이 동작한다. 파일을 그냥 더블클릭(`file://`)하면 안 된다.
- 데이터는 **그 기기 브라우저에만** 저장된다 (v0.5 로컬 저장). 아빠 폰과 엄마 폰은 서로 안 보인다. 기기 간 공유는 백엔드(2단계) 이후.
- 홈 화면에 설치한 앱과 브라우저 탭은 저장소가 **분리**될 수 있다 (특히 iOS). 설치 후 처음 열면 빈 상태일 수 있다.

## 1. PC에서 먼저 확인 (5분)
```
node tests/pwa.js          # 자동 점검: 매니페스트·아이콘·서비스 워커·오프라인
python3 -m http.server 8000
```
크롬에서 `http://localhost:8000` 열기 → F12 → Application 탭
| 확인 | 기대 결과 |
|---|---|
| Manifest | 이름·아이콘 3개, 오류 없음 |
| Service Workers | `sw.js` activated and running |
| Network에서 Offline 체크 후 새로고침 | 화면이 그대로 열림 |
| 주소창 오른쪽 설치 아이콘 | 클릭하면 앱 창으로 설치됨 |

## 2. 폰에서 테스트 (https 필요): GitHub Pages
1. 저장소 Settings → Pages → Source: "Deploy from a branch"
2. Branch: `main`(머지 후) 또는 이 개발 브랜치, 폴더 `/ (root)` → Save
3. 1~2분 뒤 `https://<계정>.github.io/Dad_Playtime/` 이 열림
   - 비공개 저장소는 Pages가 유료 플랜일 때만 된다. 안 되면 아래 임시 방법을 쓴다.
- 임시 방법(저장소 공개 없이): PC에서 서버를 띄우고 `cloudflared tunnel --url http://localhost:8000` 로 https 주소를 받는다.

## 3. 폰에서 설치
- **안드로이드 크롬**: 주소 열기 → ⋮ 메뉴 → "앱 설치" (또는 "홈 화면에 추가")
- **아이폰 사파리**: 주소 열기 → 공유 버튼 → "홈 화면에 추가" (크롬이 아니라 사파리로)

## 4. 폰 체크리스트
- [ ] 홈 화면 아이콘이 시계 모양(남색·노랑)으로 보인다
- [ ] 아이콘으로 열면 주소창 없이 전체 화면이다
- [ ] 비행기 모드로 켜도 열린다 (글꼴만 시스템 글꼴로 바뀜)
- [ ] 아이 정보·놀이 기록을 저장하고, 앱을 완전히 종료한 뒤 다시 열어도 남아 있다
- [ ] 타이머를 켜고 화면을 껐다 켜도 이상 없다
- [ ] 아래쪽 글자가 홈 바에 가리지 않는다

## 5. 업데이트 반영 방법
`index.html`을 고칠 때마다 `sw.js`의 `VERSION`을 올린다 (예: `dpn-v0.5.2`). 올리지 않으면 설치된 폰에 옛 화면이 남을 수 있다.
폰에서는 앱을 완전히 종료 후 두 번 열면 새 버전이 적용된다.
캐시가 꼬이면: 크롬 사이트 설정에서 데이터 삭제 후 재설치 (저장된 기록도 지워지니 주의).

## 6. 알려진 한계
- 기기 간 데이터 공유 없음 → 엄마 컨펌·메시지는 같은 기기에서만 보임. 실사용은 2단계 백엔드 필요.
- iOS는 한동안 사용하지 않으면 사이트 저장 데이터를 지울 수 있음.
- 푸시 알림 없음.
