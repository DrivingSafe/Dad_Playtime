# 공개 체험 버전 (서버 없는 정적 PWA)

## 방식
- 정적 파일(HTML·JS·JSON)만 GitHub Pages 같은 곳에 올린다. **서버·DB가 없다.**
- 사용자가 입력한 아이 정보·기록은 **그 사람 폰 브라우저(localStorage)에만** 저장된다. 개발자에게 전송되지 않는다.
- 장점: 개인정보를 수집하지 않아 동의·처리방침 부담이 작고, 비용이 0이다.
- 한계: 기기 간 공유 없음(엄마·아빠 기능은 한 기기에서만), 사용자 간 소통·통계 없음. 소통 기능은 Firebase 단계에서 만든다.
