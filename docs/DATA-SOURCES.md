# 데이터 출처와 확인 항목

| 데이터 | 출처 | 비고 |
|---|---|---|
| 발달 이정표(30개월·3세) | CDC "Learn the Signs. Act Early." 2026-05 개정 | 한국어 번역·단순화. CDC 제작·보증 아님을 앱 하단에 표시 |
| 놀이 카드 | CDC 팁 기반 / 이정표 기반 자체 구성 | 카드에 출처 라벨 |
| 키·몸무게 기준 | WHO Child Growth Standards (LMS) | 0~24개월 길이, 24~60개월 신장 표를 이어 붙여 24개월에서 단차 있음. 인쇄 백분위와 대조 완료 |
| 책 정보 | 『도레미곰』 전집, 「나도 안아 줘」, 『밤톨이』, 『상자가 좋아』만 출처 확인 | 나머지는 대표 예시 |

## 공개·광고 전에 확인할 것
- CDC/WHO 자료의 상업적 이용·개작 조건
- KDCA 성장도표(공공누리 유형)·K-DST는 이용하지 않음
- 아동·건강정보 수집 동의, 개인정보 처리방침
- 의료기기 소프트웨어 해당 여부 (진단 표현 금지)

## 월령별 이정표 세트
| 세트 | 항목 수 | 상태 |
|---|---|---|
| 18개월 | 15 | CDC "Milestones by 18 Months" 체크리스트와 문구 대조(v0.10) |
| 24개월 | 13 | CDC "Milestones by 2 Years" 체크리스트와 문구 대조(v0.10) |
| 30개월 | 15 | 공개 중 (기존) |
| 36개월(3세) | 12 | 공개 중 (기존 "3세 미리보기" 항목) |

- 대조 방법: 이 세션 네트워크에서 cdc.gov 직접 접속이 막혀 있어, 웹 검색 결과가 인용한 CDC 공식 페이지 문구로 항목을 확인했다. **공개 전에 원문 페이지를 직접 한 번 더 열어 확인할 것**: https://www.cdc.gov/act-early/milestones/18-months.html , https://www.cdc.gov/act-early/milestones/2-years.html
- 18·24개월 항목은 한국어로 옮기고 단순화했다. CDC 제작·보증 아님.
- CDC 안내: 두 체크리스트 나이 사이면 더 어린 쪽을 쓰고, 3주 넘게 일찍 태어난 아이는 교정 월령을 쓴다. (앱은 아직 교정 월령을 지원하지 않음)
