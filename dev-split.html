🧪 두 폰 나란히 테스트

한 화면에서 아빠 폰과 엄마 폰을 동시에 시험해요. 두 창은 서로 다른 폰처럼 저장소와 Firebase 로그인이 따로예요 (같은 Firebase 프로젝트를 써요).

  1. 왼쪽 아빠 폰: 처음 설정 → 아빠 선택 → 의견 탭 → "새로 시작하기" → 6자리 코드
  2. 오른쪽 엄마 폰: 처음 설정 화면의 "이미 가족이 시작했어요 · 초대 코드로 합류" → 코드 입력
  3. 엄마 폰에서 심부름·메모를 적으면 아빠 폰에 바로 뜨는지, 아빠가 체크·보고하면 엄마 폰에 보이는지 확인
테스트로 만든 가족은 실제 Firebase에 저장돼요. 끝나면 아빠 폰 의견 탭 → "가족 기록 모두 삭제"를 눌러 지워 주세요. "초기화"를 누르면 그 폰은 새로운 익명 사용자가 돼서 이전 가족에 다시 못 들어가요.
👨 아빠 폰profile=dad
👩 엄마 폰profile=mom
